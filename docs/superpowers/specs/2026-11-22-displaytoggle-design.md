# DisplayToggle 설계 문서

작성일: 2026-11-22
상태: 사용자 검토 대기

## 1. 목적

macOS 메뉴바에서 연결된 외부 모니터를 모니터별로 끄고 켜는 작은 앱을 만든다.
케이블을 뽑는 것과 같은 소프트웨어 연결 해제를 쓴다.
메뉴바 아이콘만 있고 Dock 아이콘과 일반 창은 없다.
MacBook에 모니터 2대(LG HDR 4K, Odyssey G70D)를 연결한 환경에서 쓴다.

### 비목표

- 밝기, 해상도 선택, 가상 디스플레이 등 다른 디스플레이 관리 기능은 넣지 않는다.
- 단축키와 자동 규칙은 이번 범위에서 제외한다. 나중에 같은 엔진 위에 추가한다.
- Mac App Store 배포는 하지 않는다. 비공개 API를 쓰기 때문이다.

## 2. 해결할 문제

참고한 기존 앱(Unplug)을 직접 써 보며 확인한 문제 세 가지다.

| # | 증상 | 기대 동작 |
|---|------|-----------|
| 1 | 모니터가 2대인데 메뉴에 3개가 나온다. G70D가 2번 나온다. | 실제 모니터당 항목 1개 |
| 2 | G70D를 끄면 메뉴에서 사라져 다시 켤 수 없다. LG의 입력을 바꿔서 우회해야 했다. | 꺼진 모니터도 목록에 남고 스위치로 다시 켤 수 있다. |
| 3 | LG를 끄면 G70D 해상도가 바뀐다. | 다른 모니터의 해상도와 배치가 유지된다. |

추가 요구: LG 모니터의 입력을 DisplayPort로 돌려 Mac이 LG 신호를 받지 못할 때는 G70D를 끌 수 없어야 한다. 이 상태에서 G70D를 끄면 화면이 0개가 된다.

원인은 아직 확인되지 않았다. 아래는 추정이다.

- 문제 1: 꺼진 G70D가 기록에 남은 상태에서 새 항목이 추가됐을 가능성.
- 문제 2: 현재 연결된 모니터만 목록에 표시하기 때문일 가능성.
- 문제 3: 모니터 하나가 빠지면 macOS가 남은 모니터의 모드를 다시 고르기 때문일 가능성.

구현 중 `systematic-debugging` 방식으로 각각 재현하고 원인을 확인한 뒤 고친다.

## 3. 접근 방식

비공개 CoreGraphics 함수 `CGSConfigureDisplayEnabled`로 모니터를 끄고 켠다.
앱은 모니터 기록(UUID 기준)을 저장해서 꺼진 모니터도 목록에 유지한다.
끄기와 켜기는 디스플레이 구성 변경 한 번(트랜잭션)으로 처리하고, 변경 전후의 해상도와 배치를 비교해 복원한다.

비공개 API라서 macOS 업데이트로 동작이 바뀔 수 있다. 심볼은 `dlsym`으로 찾고, 찾지 못하면 앱이 모니터 토글을 비활성화한 채 오류를 메뉴에 표시한다.

## 4. 구성 요소

패키지 구조는 Swift Package이고, 빌드 스크립트가 `.app` 번들을 만든다. Xcode 프로젝트는 쓰지 않는다.

| 구성 요소 | 책임 |
|-----------|------|
| `DisplayBackend` (프로토콜) | 모니터 목록 조회, 활성화/비활성화, 모드 조회/설정. 실제 구현은 CoreGraphics, 테스트용은 가짜 구현. |
| `DisplayRegistry` | 본 적 있는 모니터를 UUID, 이름, 마지막 모드와 함께 JSON 파일로 저장하고, 현재 연결된 모니터와 합쳐서 목록을 만든다. |
| `SafetyGuard` | 끄기 요청이 안전한지 판단한다. 순수 로직이라 단위 테스트가 가능하다. |
| `DisplayController` | 끄기/켜기 실행, 해상도·배치 스냅샷과 복원, 안전장치 호출. |
| `ReconfigWatcher` | `CGDisplayRegisterReconfigurationCallback`으로 구성 변경을 감시하고 복구 규칙을 적용한다. |
| `MenuBarController` | `NSStatusItem`과 `NSMenu`를 만들고 모니터별 스위치 항목을 표시한다. |

### 모니터 목록 규칙

- 목록은 "현재 연결된 모니터"와 "기록에 있는 꺼진 모니터"의 합집합이다. UUID가 같으면 항목 하나로 합친다.
- 같은 UUID는 항목이 둘 생길 수 없다. 이것이 문제 1의 수정 지점이다. 원인이 다르면 재현 후 수정한다.
- 이름이나 모델 정보가 없는 임시 항목은 목록에 표시하지 않는다.

## 5. 메뉴 동작

```
Displays
  LG HDR 4K          [켬]
  Odyssey G70D       [꺼짐]   ← 꺼진 상태로 남아 스위치로 다시 켤 수 있다
─────────────
  모두 켜기
  About DisplayToggle
  Quit
```

- 스위치를 누르면 해당 모니터만 끄거나 켠다.
- 끌 수 없는 모니터는 스위치를 비활성화하고 이유를 한 줄 표시한다. 예: "마지막 화면은 끌 수 없음".
- "모두 켜기"는 기록에 있는 모든 모니터를 켠다. 항상 누를 수 있다.
- About에는 GitHub 저장소와 Buy me a coffee 링크를 둔다.
- Quit 시에는 끈 모니터를 모두 켜고 종료한다. (미결 사항 참고)

## 6. 안전장치

| 규칙 | 내용 |
|------|------|
| G1 | 끄고 나면 켜진 모니터가 0개가 되는 요청은 거부한다. 켜진 모니터는 `CGDisplayIsActive` 기준이다. |
| G2 | G1은 메뉴를 표시할 때와 끄기를 실행하기 직전에 한 번씩 검사한다. 사이에 상태가 바뀔 수 있다. |
| G3 | 구성 변경 콜백에서 켜진 모니터가 0개가 되면 기록에 있는 모니터를 모두 켠다. |
| G4 | 앱을 시작할 때 이전 세션에서 꺼 둔 모니터를 모두 켠다. 꺼짐 상태는 세션 안에서만 유효하다. |
| G5 | 내장 디스플레이는 실제로 켜져 있을 때만 켜진 모니터 수에 센다. 덮개를 닫은 상태는 센다고 가정하지 않는다. |

### LG 입력 전환 시나리오

1. LG 입력을 DisplayPort(다른 기기)로 바꾼다. Mac은 LG 신호를 잃고 켜진 모니터가 G70D 하나가 된다.
2. G1에 따라 G70D의 스위치는 비활성화되고 끌 수 없다.
3. 이미 G70D를 꺼 둔 상태에서 LG 신호가 사라지면 켜진 모니터가 0개가 되므로 G3이 G70D를 자동으로 켠다. 앞서 겪은 "LG 입력을 바꿔서 우회해야 하는 상황"을 막는 장치다.

## 7. 해상도와 배치 유지

- 끄기나 켜기 직전에 켜진 모든 모니터의 모드(해상도, 주사율, 스케일)와 좌표를 저장한다.
- 구성 변경이 끝난 뒤 저장한 값과 비교한다. 다르면 같은 구성 트랜잭션에서 복원한다.
- 복원이 실패하거나 모드가 더 이상 지원되지 않으면 그대로 두고 메뉴에 짧은 경고를 표시한다.
- 켜질 때는 기록에 저장된 마지막 모드를 우선 적용한다.

## 8. 저작권과 라이선스

- Unplug(MIT)의 소스 코드를 읽거나 복사하지 않고 처음부터 작성한다. 사용하는 것은 "비공개 API로 모니터를 비활성화한다"는 공개된 기법뿐이다.
- 앱 이름, 아이콘, 문구는 모두 새로 만든다. 아이콘은 SF Symbols 또는 직접 그린 도형을 쓴다.
- 이 프로젝트는 별도의 라이선스(MIT 권장)로 배포한다. 라이선스 선택은 사용자 결정이다.
- 외부 의존성은 0개로 시작한다.

## 9. 빌드와 배포

- 최소 지원 버전은 macOS 13 이상으로 시작한다. 사용 환경은 macOS 27.2.1이다. 검증 후 조정한다.
- `build.sh`가 `swift build -c release`로 빌드하고 `.app` 번들을 만든다. `LSUIElement`를 설정해 Dock 아이콘을 숨긴다.
- 배포는 GitHub Releases에 zip으로 올린다.
- 처음에는 서명 없이(ad-hoc) 배포한다. 받는 사람은 격리 속성을 직접 풀어야 한다. 사용자가 늘면 Developer ID 서명과 공증을 검토한다.

## 10. 테스트 전략

- **단위 테스트**: `SafetyGuard` 규칙(G1~G5), `DisplayRegistry`의 합집합과 중복 제거, 스냅샷 비교를 가짜 `DisplayBackend`로 검증한다.
  - 모니터 1대일 때 끄기 거부
  - 2대 중 1대 끄기 허용, 꺼진 항목 유지
  - 꺼진 상태에서 나머지 모니터가 사라지면 자동 복구
  - 같은 UUID가 두 번 들어와도 항목 1개
- **수동 테스트 체크리스트** (실제 하드웨어, 별도 문서로 관리):
  - G70D 끄기, 목록 유지, 다시 켜기
  - LG 끄기, G70D 해상도 유지
  - LG 입력 전환 후 G70D 끄기 거부
  - 앱 재시작 후 꺼진 모니터 복구
- 비공개 API 호출 자체는 자동 테스트하지 않는다. 화면이 꺼지므로 수동 체크리스트로 확인한다.

## 11. 미결 사항

1. Quit 시 끈 모니터를 모두 켤지, 그대로 둘지. 기본값은 모두 켜기다.
2. 최소 macOS 버전(13으로 시작).
3. 프로젝트 라이선스(MIT 권장).
4. 문제 1~3의 실제 원인은 구현 중 재현해서 확인한다. 추정이 틀리면 해당 수정 방식을 바꾼다.
5. macOS 27.2.1과 Apple M6에서 `CGSConfigureDisplayEnabled`가 동작하는지는 구현 첫 단계에서 확인한다. 동작하지 않으면 이 설계는 재검토한다.
